# Sales Bonus Calculator

Веб-приложение на нативном JavaScript для анализа данных о продажах. Проект обрабатывает массивы данных, составляет рейтинг сотрудников по доходности и рассчитывает индивидуальные бонусные вознаграждения.

## Функциональность
* **Обработка данных:** Парсинг и анализ структуры данных о продажах.
* **Ранжирование:** Построение рейтинга продавцов на основе итоговой выручки.
* **Система бонусов:** Автоматизированный расчет премий по заданным алгоритмам.
* **Чистая архитектура:** Использование "чистых функций" (pure functions) без побочных эффектов, что позволяет корректировать особенности расчетов без изменения основного кода.

## Технологии
* Нативный JavaScript (ES6+)
* HTML5

## Запуск проекта

1. Откройте файл `index.html` в любом современном браузере.
2. Откройте консоль разработчика (DevTools, клавиша F12 или Ctrl+Shift+I). Результаты вычислений (рейтинг и бонусы) будут выведены туда.

*Примечание: Чтобы протестировать приложение на разных наборах данных, измените путь к скрипту датасета в файле `index.html` (доступны `data/dataset_1.js`, `data/dataset_2.js` и `data/dataset_3.js`).*
